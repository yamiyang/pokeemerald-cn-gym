# 野外遇敌重制（全量投放）

## 为什么原本都是老精灵

`pokeemerald-expansion` 的设计原则是「机制现代化，内容保持原味」：1000 多只精灵的数据、招式、进化、图鉴条目全部启用
（`include/config/species_enabled.h` 里 9 个世代都是 `TRUE`），但**遇敌表仍是 2004 年那张**。

实测原始数据：

| 项目 | 数值 |
|---|---|
| `src/data/wild_encounters.json` 地图条目 | 388（丰缘 135） |
| 用到的物种 | 211 个，**全是 Gen3** |
| 我们编的是 emerald | 火红/叶绿那 240 条用不到 |

## 三个版本

| 版本 | 做法 | 野外可直接遇到 |
|---|---|---|
| 原版 | — | 211 |
| v1 `retint_wild.py` | 13 个生态池，每图 3 个新面孔 | 276 |
| **v2 `retint_wild_v2.py`** | **全国图鉴全量投放** | **871** |

v1 的问题：池子只有 6~16 只，全图加起来才 80 个新物种，剩下的 600 多只永远见不到。

## v2 算法

```
python3 design/retint_wild_v2.py            # 试跑 + 覆盖率报告
python3 design/retint_wild_v2.py --apply    # 写入（有遗漏会拒绝写入）
```

### 1. 候选物种

从 `species_info` 的 `.natDexNum` 归并出**全国图鉴 1007 个物种**（同一编号取代表形态），再排除：

| 排除 | 数量 | 依据 |
|---|---|---|
| 传说 / 幻兽 / 究极异兽 / 悖谬 | 116 | 直接读源码里的 `.isSubLegendary` / `.isRestrictedLegendary` / `.isMythical` / `.isUltraBeast` / `.isParadox`，不靠名字猜 |
| 化石 | 21 | 名单（走化石复活，不该路边刷） |
| **目标** | **870** | 含御三家 80 只（作为稀有投放，想剔除改一个集合即可） |

### 2. 生态分配（两阶段）

13 个生态各有「主题属性」：火山=火、冰室=冰、沙漠=地/岩、森林=草/虫、神社=幽灵/超能……

- **第一阶段**：主题属性物种优先填自己的主题生态，占该生态槽位的 60%
- **第二阶段**：剩余物种按容量比均衡填剩下的 40%

这样火山不会变成普通系动物园（火系 45/121 槽 ≈ 37%，加上原生的 Slugma/Torkoal/Numel 后过半）。

### 3. 槽位与稀有度

陆地 12 格权重 `20 20 10 10 10 10 5 5 4 4 1 1`，每个生态按需求替换 6~10 格，**至少保留 2 个原生种**维持地方特色。

稀有度按种族值分四档，与槽位权重对齐（低权重槽 = 稀有）：

| 档 | 种族值 | 目标槽位 |
|---|---|---|
| 1 常见 | < 400 | 20% |
| 2 少见 | 400–479 | 10% |
| 3 稀有 | 480–539 | 5% |
| 4 极稀有 | ≥ 540 | 1% |

### 4. 等级门槛

种族值越高，只能出现在越晚的地图：

| 种族值 | 最早出现 |
|---|---|
| < 380 | 4 级 |
| 380–419 | 12 级 |
| 420–459 | 20 级 |
| 460–499 | 28 级 |
| 500–539 | 34 级 |
| 540–579 | 40 级 |
| ≥ 580 | 45 级 |

放不下时逐级放宽（12/20/不限），并把该槽的 `min_level`/`max_level` 抬到门槛——
所以快龙只会在后期地图以 45 级出现，不会在 101 号路。

### 5. 水域 / 碎岩

- 水面、钓鱼只放水属性（含冰/龙系水生）
- 碎岩只放岩/地/钢/格斗/虫
- 海图的陆地槽（小岛沙滩）保持原版不动

### 6. 二次铺开

首轮每物种只占 1 个槽，会有 600 多种「只挂在一个 1% 槽上」的情况。第二轮把还有空位的槽补上，
让 463 个物种至少出现 2 次，其余受槽位总量限制保持 1 次。

## 地形约束（硬规则）

`design/audit_encounters.py` 检查：

1. 水域槽里的物种必须带水系
2. 沙漠不许出现火系
3. 火山陆地不许出现水/冰，且必须有火系
4. 冰室不许出现火系
5. 干旱陆地不许出现纯水栖
6. 海图上的陆地保持原版不动

当前结果：**违规 0 处**。

## 图鉴联动

**注意**：野外现在有 871 个物种，但丰缘图鉴仍只有 292 条（v1 时补的）。
不在丰缘图鉴里的物种，遭遇后只登记全国图鉴，地区图鉴列表里看不到。

要不要把 871 个全部补进地区图鉴是另一个决定——那会把图鉴列表从 292 条拉到 871 条，
UI 能用但翻页很长，且 `HOENN_DEX_COUNT` 变动需要单独验证。

## 编译提醒

改完 JSON 必须走生成 + 编译两步，且 `make` 要显式带 `EXE=.exe`（详见 [RANDOM_TRAINERS.md](RANDOM_TRAINERS.md) 的「编译踩坑」）：

```bash
make EXE=.exe generated     # 重新生成 src/data/wild_encounters.h
make EXE=.exe -j2
```

**编完必须发布**：`pokeemerald.gba` 出来后要手动覆盖到 `D:\poke_cn\PokeEmerald_CN_GymRemake.gba`。
2026-11-24 就踩过这个坑——01:33 的编译成功了，但成品没覆盖过去，玩家手里还是 01:14 的旧包，
于是「草丛遇到的还是老精灵」「NPC 队伍没变」全是假象，源码和 ROM 都没问题。

每次发布后核对 MD5 与时间戳：

```bash
cp pokeemerald.gba /d/poke_cn/PokeEmerald_CN_GymRemake.gba
md5sum pokeemerald.gba /d/poke_cn/PokeEmerald_CN_GymRemake.gba   # 两个必须一致
```

**反解验证**（确认 ROM 里装的是新表，不是旧包）：

- 遇敌表：`gWildMonHeaders` @ map 文件地址，逐条读 `.landMonsInfo`，
  12 槽的 `species` 应与 `wild_encounters.json` 完全一致；抽查 101 号路出现木木枭、敲音猴即说明是新数据。
- 队伍表：`gTrainers[DIFFICULTY_NORMAL]` 在 `gTrainers + 855 × 52` 处，
  且 `build/emerald/src/data.o` 的 mtime 必须晚于 `src/data/trainers.h`。
