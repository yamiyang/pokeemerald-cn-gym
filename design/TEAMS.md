# 丰缘八馆 · 队伍重做方案（v2 · 含压轴提前进化）

**基底**：`rh-hideout-chinese/pokeemerald-expansion`（中文）
**改动文件**：`src/data/trainers.party`（271KB，855 个训练师，纯文本）
**验证方式**：`D:\tools\dex.py`，逐只核对进化等级与学招等级
**当前结果**：**0 处违规，5 处压轴提前进化**

---

## 一、规则怎么落地

| 约束 | 做法 | 实测 |
|---|---|---|
| **压轴允许提前 ≤10 级进化（鼓励）** | 每队**最后一只**可用进化形态，前提是正常进化等级 − 当前等级 ≤ 10。校验器输出 `★` 标记 | 5 处，全部在窗口内 |
| **非压轴严格禁止提前进化** | 第二只、第三只……必须卡在正常进化等级之上，一只都不放 | 已核 |
| 不超前学招 | 只用该等级**已经学会**的升级招式，TM 一律不加 | 已核 |
| 不堆等级 | 等级曲线沿用原版（15 → 46），强度来自配招、特性、AI、进化形态 | 已核 |
| 不全同属性 | 主属性保留，靠副属性和外挂补盲，每队至少两只非本馆属性 | 见各馆 |
| 讲联防 | 每队专门配 1–2 只堵自己弱点的 | 见各馆 |
| 参考热门队 | Emerald Kaizo、Radical Red、Modern Emerald、Smogon 天气核心 | 见第四节 |

**为什么只给压轴开口子**：压轴是玩家唯一会记住的那只。把进化形态给它，等于给一场战斗画一个明确的"最后一关"；如果全队都提前进化，那就是整体抬数值，玩家只能靠刷级追平——那正是我们要避免的。

**平衡阀不是等级，是特性和速度**：请假王「懒惰」每两回合才动一次、铁掌力士速度 50、达摩狒狒特防 55、雷电兽没强化招。这些都是能被打穿的洞，不是无敌。

**验证命令**：

```
python D:\tools\dex.py validate D:\tools\teams_spec.json   # 八馆
python D:\tools\dex.py validate D:\tools\teams_e4.json     # 四天王 + 冠军
python D:\tools\dex.py moves KINGDRA 46                    # 查某只在某级能学什么
python D:\tools\dex.py info PELIPPER                       # 查进化线与特性
python D:\tools\dex.py check SLAKING 31 "Throat Chop" "Slash" "Sucker Punch" "Slack Off" -ace
```

> 招式名带空格要加引号。`-ace` 表示"这只按压轴算，允许提前 ≤10 级进化"；去掉它就会报错——这个开关就是为了防止非压轴偷偷越级。

**结构变了**：上一版是"煤炭龟压轴"，这一版把**天气手挪到第三位**——晴天队永远是日照手先上、爆发手收尾，竞技队一直这么排。你会在第三只吃到晴天，然后在第五只被达摩狒狒一记火焰拳带走。

**★ 这就是原版设定**：GB 玩家记得的"千里那只请假王"就是 31 级。上一版我按"不提前进化"把它删了，改成晃晃斑压轴，其实是丢掉了这个馆的记忆点。现在恢复了。

**联防**：普通只弱格斗。靠招式覆盖而不是属性：深渊突刺/突袭打幽灵，金属爪打岩石冰（变隐龙/晃晃斑位），幻象光线打格斗。

## 七、等你定的两件事

1. **要不要我直接写进 `trainers.party` 并编一版**：八馆 + 四天王 + 冠军一次改完，先 `git init` 存一份原始状态，你打一场验证手感。重点想看两处——藤树那只 19 级铁掌力士是不是太硬，亚莎的达摩狒狒在晴天下是不是过强。
2. **千里要不要再加一只梦妖**（幽灵，31 级合法）：现在请假王压轴已经解决了"普通系没威慑"的问题，加幽灵会把这一馆变成"反格斗专门店"。加了更立体，不加人设更纯——我倾向不加，请假王本身已经够有记忆点。
